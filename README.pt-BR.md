# Concept Studio

Plataforma aberta de representação visual do conhecimento. Primeiro mapas conceituais, depois mapas mentais e outros diagramas.

## Desenvolvimento

```sh
npm ci
npm start
npm run build
npm test -- --watch=false
```

Acesse http://localhost:4200/editor. Projeto em estágio inicial; persistência e salas temáticas ainda não implementadas.
