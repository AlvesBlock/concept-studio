# Interactive editor — first increment

Create concepts by double-click or toolbar, create linking phrases, select and edit text, connect alternating node types by two clicks, delete selected cells and start an empty map. X6 remains the live editor state; document synchronization, persistence, drag-to-connect ports and inline text editing are not implemented yet. New document clears history; focal question is not part of X6 undo history. Browser integration and unit tests require local validation.
