# Visual presentation

A separate presentation preview renders the full semantic snapshot as SVG, independent of the editor viewport. Academic, minimal and original themes; optional automatically seeded thematic columns, editable group titles/colors and membership, optional concept omission, JPEG/PNG/SVG and browser print/PDF. Source is never mutated. Group settings are temporary; no saved presentation configuration yet. Grouped layout is heuristic, not an obstacle-avoiding router. Raster export is bounded to 8192 pixels per axis and 32 megapixels. No new dependencies.
