# Concept map workflow

Selected node overlay handle supports pointer drag to another node or empty canvas. A concept-to-concept drop creates a proposition; a phrase-to-blank drop adds a branch. Enter advances from a newly created phrase to its destination. Manual localStorage save/open and validated JSON import are available. No autosave, IndexedDB, graphical export or browser integration tests yet. Local storage is per browser/origin and is not a backup. Deploy settings unchanged.
